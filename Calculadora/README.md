# Calculadora em Java

Este projeto é uma calculadora simples desenvolvida em Java por um estudante que está migrando para a linguagem e praticando os primeiros conceitos de desenvolvimento com interface gráfica.

## Objetivo

O objetivo deste projeto foi aprender e aplicar:

- criação de interfaces com Swing
- uso de layouts e componentes visuais
- lógica básica de cálculos matemáticos
- manipulação de eventos de clique
- organização inicial de código em Java

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Números decimais
- Botão de limpar (C)
- Tratamento básico para divisão por zero
- Visor com resultado em tela

## Tecnologias utilizadas

- Java
- Swing
- AWT

## Como executar

1. Abra o terminal ou prompt de comando.
2. Acesse a pasta do projeto.
3. Compile o arquivo Java:

```bash
javac src/Calculadora.java
```

4. Execute a aplicação:

```bash
java -cp src Calculadora
```

## Observações

Este é um projeto didático e inicial. A ideia é praticar conceitos básicos de Java enquanto cria uma aplicação funcional e fácil de entender.

Com o tempo, ele pode evoluir para:

- código mais organizado em métodos
- separação por classes
- melhorias na interface visual
- suporte a mais operações e funcionalidades

## Aprendizado

Esse projeto representa um passo importante no aprendizado de Java, especialmente na criação de aplicativos com interface gráfica e na lógica de programação aplicada a problemas reais.
